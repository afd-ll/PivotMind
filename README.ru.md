## Что такое PivotMind

PivotMind — это **когнитивный движок, вдохновлённый мозгом**,
построенный на [TraceWisdomNetwork](#tracewisdomnetwork) +
[Хеббовском обучении](#core-mechanisms) +
[Многослойном диффузионном рассуждении](#multi-layer-diffusion-engine).
Никаких трансформеров. Никаких эмбеддингов. Никакого обратного распространения.
Только узлы, рёбра, активация и затухание — под управлением неумолимых фоновых часов.

**Текущая версия: v0.5.5** — 14 зон мозга/подсистем (все полностью реализованы), эмерджентная система частей речи, параллельные обучающие модули, PFE-рассуждения, 512-мерные векторы признаков.

**Объём кода: 85 исходных файлов (~48 600 строк C) + 89 заголовочных (~12 600 строк) + инструменты/тесты/демо (~13 000 строк) = ~74 000 строк.**

### TraceWisdomNetwork

Каждое понятие — это узел. Совместная встречаемость создаёт ребро. Рёбра несут тройной атрибут:
**вес × уверенность × мотивационное смещение**.
Одиннадцать подтопологий (словарь / семантика / эмоция / синтаксис / контекст / домен / прагматика / культура / концепт / мастер / шаблон)
формируют каждая независимую сеть рассуждений, связанную межтопологическими связями с O(1) индексацией через списки смежности.
Активация диффундирует одновременно по слоям, а конкуренция выбирает победителя в качестве выхода.

### Почему именно так

| Традиционная LLM       | PivotMind                                              |
|-----------------------|--------------------------------------------------------|
| Предсказание токенов, без состояния | Активация узлов, непрерывное внутреннее состояние       |
| Офлайн-обучение на батчах через градиенты | Онлайн-обучение по Хеббу + Skip-gram предобучение          |
| Единое пространство эмбеддингов | 11 независимых подтопологий + 512-мерные векторы признаков |
| Чёрный ящик нейросети | Явные пути узлов-рёбер, полная трассируемость            |
| Требуется GPU + большая VRAM | Только pthread + OpenMP, работает на ARM          |
| Инференс отделён от обучения | Диалог И ЕСТЬ обучение                    |
| Нет физиологического самоконтроля | Интероцептивный мониторинг, 3-уровневый отклик здоровья |
| Заморожена после обучения | 24/7 непрерывное фоновое обучение                    |

## Архитектура зон мозга

PivotMind моделирует функциональное деление коры мозга млекопитающих — 14 зон мозга/подсистем, каждая с собственными обязанностями, общающихся через сигнальную шину Thalamus. **Все 13 зон полностью реализованы, без заглушек.**

                          │  + Prefrontal Exec PFE │ ← Оркестратор 6-режимных рассуждений
                          └──────────┬───────────┘
                                     │ Signal Bus
        ┌────────┬────────┬─────────┼─────────┬────────┬────────┬────────┐
        ▼        ▼        ▼         ▼         ▼        ▼        ▼        ▼
   ┌────────┐┌──────┐┌──────┐┌──────────┐┌──────┐┌──────┐┌──────┐┌──────────┐
   │Hippo-  ││ DMN  ││Amyg- ││ Perception││Broca ││Cere- ││Brain-││Hypothal- │
   │campus  ││      ││dala  ││  Cortex   ││      ││bellum││stem  ││  amus    │
   │Memory  ││Dream ││Emo-  ││  Web     ││Template││BPTT  ││Circ- ││ Drives   │
   │Consol. ││      ││tion  ││  Search  ││Builder││Tuner ││adian ││          │
   └────────┘└──────┘└──────┘└──────────┘└──────┘└──────┘└──────┘└──────────┘
                                     │
                          ┌──────────┴──────────┐

## Основные механизмы

### Многослойный диффузионный движок

Вход токенизируется скользящим окном, затем диффундирует одновременно по слоям:

- **Vocabulary** — прямое буквальное сопоставление, быстрое извлечение
- **Semantic** — межтопологические ассоциации по 11 подтопологиям
- **Template** — распознавание синтаксических паттернов, направляющее вставку коннекторов
- **Emotion** — взвешивание по валентности × возбуждению, модулирующее приоритет кандидатов

**Улучшение v0.5.5**: Фильтрация служебных слов — `is_function_word()` проверяет ~130 китайских и английских служебных слов на 3 этапах конвейера (обновление активного набора, взвешенная оценка, вывод), предотвращая доминирование высокосвязных служебных слов в выводе.

### Оркестрация рассуждений (PFE)

Prefrontal Executive автоматически оценивает сложность вопроса и выбирает один из 6 режимов рассуждений:

| Режим       | Ключевые слова-триггеры        | Стратегия                              |
|------------|-------------------------|---------------------------------------|
| DIRECT     | по умолчанию            | Одиночная диффузионная ассоциация          |
| DECOMPOSE  | why / because           | Определение → причинность → синтез     |
| COMPARE    | compare / difference    | Извлечение атрибутов → контраст       |
| HOWTO      | how to                  | Предусловия → последовательность шагов         |
| ABDUCE     | what if / assume        | Базовая линия → цепная реакция             |
| ANALOGY    | analogy / similar       | Структурное отображение                    |

Подцели декомпозируются рекурсивно. Обнаружение конфликтов + 5D-соревнование IdeaArena выбирают оптимальные пути. Веса стратегий поддерживают EMA-самообучение с сохранением.

### Эмерджентная система частей речи (Emergent POS) **NEW v0.4.3** *(подробнее в англ./кит. версии)*

Человек предоставляет только 3-5 «якорных» слов на класс (~50 слов). Система инициализирует центроиды из 512-мерных хеббовских векторов якорных слов. Во время выполнения новые слова классифицируются по косинусному сходству с ближайшим центроидом (EMA-микронастройка). При превышении 10 слов в неклассифицированном пуле — появляется новый класс.

### Интероцептивный самоконтроль

Непрерывно отслеживает RSS-память, скорость роста связей и задержку рассуждений с 3-уровневым откликом:

| Уровень         | Состояние   | Действие                                            |
|---------------|-------------|---------------------------------------------------|
| 🟢 GREEN      | Норма      | Нормальная работа                                  |
| 🟡 YELLOW     | Предупреждение | Лог-алерт + повышение порога обучения              |
| 🔴 RED        | Критично    | Экстренное сохранение + массовая обрезка слабых рёбер |

## Система обучения *(подробнее в англ./кит. версии)*

### Система предобучения

Skip-gram / CBOW предобучение словесных эмбеддингов (1 624 строки): динамический размер окна, negative sampling, momentum, gradient clipping, планирование скорости обучения.

### Матрица обучающих модулей

| Модуль | Метод | Описание |
|--------|------|----------|
| **Autonomic** | Hebbian онлайн | Усиление при совстречаемости, 16-шардовые параллельные обновления |
| **Active** | 24/7 фоновый | Автоматическое приобретение знаний, анализ связей понятий |
| **Self** | На основе любопытства | Выборка любопытства → глубокий обход → обзор знаний → самокоррекция |
| **BPTT** | Временное обратное распространение | RNN + Linear слои, Adam оптимизатор (lr=0.001) |

### Предотвращение катастрофического забывания

На основе EWC (Elastic Weight Consolidation): матрица информации Фишера маркирует важность параметров, селективно защищая предыдущие знания.

## Нейросетевая подсистема *(подробнее в англ./кит. версии)*

**Тензор**: Многомерные тензоры create/destroy/broadcast/clone/view (889 строк)  
**Слои**: 8 типов (LINEAR/RELU/SIGMOID/TANH/SOFTMAX/DROPOUT/EMBEDDING/SIMPLE_RNN)  
**LSTM** (713 строк): Полный LSTM, двунаправленный, layer normalization  
**GRU** (621 строка): Полный GRU, вентили обновления/сброса, двунаправленный  
**Модель**: Многослойное стекирование, forward pass, MSE-потери, сериализация  
**Тренер**: Мини-батч обучение, планирование скорости обучения  
**Оптимизатор**: SGD / Adam (β1=0.9, β2=0.999) / RMSprop  
**Квантизация**: FP16 / INT8 / INT4 / INT2 снижение точности  
**Прунинг**: MAGNITUDE / RANDOM / GRADIENT / STRUCTURED стратегии  
**Attention**: Bahdanau / Luong / Self-Attention / Multi-Head Attention

## Быстрый старт

### Сборка

```bash
# Требуется GCC + pthread + OpenMP (нужны libcurl + openssl, иначе без зависимостей)
make all

# Кросс-компиляция для ARM
make CC=aarch64-linux-gnu-gcc all

# Отладочная сборка (с ASAN детекцией адресов/UB)
make asan

# Запуск всех юнит-тестов
make test
```

### Запуск

```bash
# Интерактивный шлюз (рекомендуется)
./build/bin/pivotmind_gateway

# Интерактивный CLI-режим
./build/bin/digital_life
```

Шлюз по умолчанию слушает на `:8080`, с HTML-дашбордом (авто-обновляемый JS) по `/`.

### Примеры API

```bash
# Задать вопрос
curl -X POST http://localhost:8080/chat \
  -H "Content-Type: application/json" \
  -d '{"query":"What is consciousness?"}'

# Скормить обучающий материал
curl -X POST http://localhost:8080/learn \
  -H "Content-Type: application/json" \
  -d '{"text":"Consciousness is the subjective experience produced by neural networks."}'

# Проверить статус
curl http://localhost:8080/status

# Проверка здоровья
curl http://localhost:8080/health
```

### Цели сборки

| Команда              | Описание                                |
|----------------------|--------------------------------------------|
| `make all`           | Собрать все цели                          |

| `make corpus-train`  | Инструмент обучения на корпусе                   |
| `make template-build`| Инструмент построения шаблонов                   |

## Известные ограничения

- **Связность генерации** — ассоциативный путь даёт менее естественный текст, чем LLM (активно итерируемся)
- **Нет GPU-ускорения** — Чистый CPU + pthread + OpenMP
- **Бинарные файлы состояния** — Не кросс-архитектурные (x86_64 и ARM; планируется JSON/MessagePack формат)
- **Только один узел** — Нет поддержки распределённой мультиузловой топологии
