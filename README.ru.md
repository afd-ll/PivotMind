## Что такое PivotMind

PivotMind — это **когнитивный движок, вдохновлённый мозгом**,
построенный на [TraceWisdomNetwork](#tracewisdomnetwork) +
[Хеббовском обучении](#core-mechanisms) +
[Многослойном диффузионном рассуждении](#multi-layer-diffusion-engine).
Никаких трансформеров. Никаких эмбеддингов. Никакого обратного распространения.
Только узлы, рёбра, активация и затухание — под управлением неумолимых фоновых часов.

**Текущая версия: v0.4.1** — 10 зон мозга, PFE-рассуждения, соревнование IdeaArena, онлайн-хеббовское обучение.

### TraceWisdomNetwork

Каждое понятие — это узел. Совместная встречаемость создаёт ребро. Рёбра несут тройной атрибут:
**вес × уверенность × мотивационное смещение**.
Десять подтопологий (словарь / семантика / эмоция / синтаксис / контекст / домен / прагматика / культура / концепт / шаблон)
формируют каждая независимую сеть рассуждений, связанную межтопологическими связями.
Активация диффундирует одновременно по слоям, а конкуренция выбирает победителя в качестве выхода.

| Традиционная LLM       | PivotMind                                              |
|-----------------------|--------------------------------------------------------|
| Предсказание токенов, без состояния | Активация узлов, непрерывное внутреннее состояние       |
| Офлайн-обучение на батчах через градиенты | Онлайн-обучение в реальном времени по Хеббу          |
| Единое пространство эмбеддингов | 10 независимых подтопологий                          |
| Чёрный ящик нейросети | Явные пути узлов-рёбер, полная трассируемость            |
| Требуется GPU + большая VRAM | Только pthread + OpenMP, работает на ARM          |
| Инференс отделён от обучения | Диалог И ЕСТЬ обучение                    |
| Нет физиологического самоконтроля | Интероцептивный мониторинг, 3-уровневый отклик здоровья |

## Архитектура зон мозга

PivotMind моделирует функциональное деление коры мозга млекопитающих — 10 зон, каждая с собственными обязанностями, общающихся через сигнальную шину Thalamus.

```
                          ┌──────────────────────┐
                          │   Prefrontal Cortex    │ ← Вход диалога / решений
                          │  + Prefrontal Exec PFE │ ← Оркестратор рассуждений
                          └──────────┬───────────┘
                                     │ Signal Bus
        ┌────────┬────────┬─────────┼─────────┬────────┬────────┬────────┐
        ▼        ▼        ▼         ▼         ▼        ▼        ▼        ▼
   ┌────────┐┌──────┐┌──────┐┌──────────┐┌──────┐┌──────┐┌──────┐┌──────────┐
   │Hippo-  ││ DMN  ││Amyg- ││ Perception││Broca ││Cere- ││Brain-││Hypothal- │
   │campus  ││      ││dala  ││  Cortex   ││      ││bellum││stem  ││  amus    │
   │Memory  ││Dream ││Emo-  ││  Web     ││Template││BPTT  ││Circ- ││ Drives   │
   │Consol. ││      ││tion  ││  Search  ││Builder││Tuner ││adian ││          │
   └────────┘└──────┘└──────┘└──────────┘└──────┘└──────┘└──────┘└──────────┘
                                     │
                          ┌──────────┴──────────┐
                          │    Thalamus           │ ← Сигнальная шина + гейт ресурсов
                          └─────────────────────┘
```

| Зона мозга       | Файл                       | Функция                                                       |
|--------------------|----------------------------|----------------------------------------------------------------|
| Prefrontal         | `prefrontal.c`             | Генерация диалога, диффузия → оценка ACC                  |
| Prefrontal Exec    | `prefrontal_executive.c`   | Оркестрация 6 режимов рассуждений, декомпозиция задач             |
| Hippocampus        | `hippocampus.c`            | Консолидация памяти, реплей QA, связь с восприятием            |
| DMN                | `dmn.c`                    | Default Mode Network: ассоциации во сне, исследование в покое      |
| Amygdala           | `amygdala.c`               | Выборка эмоциональной валентности, баланс explore / exploit          |
| Perception Cortex  | `perception.c`             | Веб-поиск, семантический конвейер article_reader                   |
| Broca's Area       | `broca.c`                  | Авто-построение и планирование затухания шаблонов                    |
| Cerebellum         | `cerebellum.c`             | Тонкая настройка BPTT, защита аппаратных ресурсов                 |
| Hypothalamus       | `hypothalamus.c`           | Регуляция динамики драйвов, связь с циркадными ритмами                  |
| Thalamus           | `thalamus.c`               | Сигнальная шина, гейтинг ресурсов, межзонная маршрутизация              |
| Brainstem          | `brainstem.c`              | Циркадное сердцебиение, затухание активации, спонтанная активация  |
| Cingulate (ACC)    | `cingulate.c`              | 4D-оценка последовательностей (семантика + шаблон + эмоция + длина) |
| IdeaArena          | `idea_arena.c`             | Мультикандидатный 5D конкурентный отбор                       |

## Основные механизмы

### Многослойный диффузионный движок

Вход токенизируется скользящим окном, затем диффундирует одновременно по слоям:

- **Vocabulary** — прямое буквальное сопоставление, быстрое извлечение
- **Semantic** — межтопологические ассоциации по 10 подтопологиям
- **Template** — распознавание синтаксических паттернов, направляющее вставку коннекторов
- **Emotion** — взвешивание по валентности × возбуждению, модулирующее приоритет кандидатов

Латеральное торможение обеспечивает разнообразие выхода.

### Оркестрация рассуждений (PFE)

Prefrontal Executive автоматически оценивает сложность вопроса и выбирает один из 6 режимов рассуждений:

| Режим       | Ключевые слова-триггеры        | Стратегия                              |
|------------|-------------------------|---------------------------------------|
| DIRECT     | по умолчанию                 | Одиночная диффузионная ассоциация          |
| DECOMPOSE  | why / because           | Определение → причинность → синтез     |
| COMPARE    | compare / difference    | Извлечение атрибутов → контраст       |
| HOWTO      | how to                  | Предусловия → последовательность шагов         |
| ABDUCE     | what if / assume        | Базовая линия → цепная реакция             |
| ANALOGY    | analogy / similar       | Структурное отображение                    |

Подцели декомпозируются рекурсивно (настраиваемая глубина). Обнаружение конфликтов + соревнование IdeaArena
выбирают оптимальные пути, порождая объяснимые цепочки рассуждений.

### Интероцептивный самоконтроль

Непрерывно отслеживает RSS-память, скорость роста связей и задержку рассуждений с 3-уровневым откликом:

| Уровень         | Состояние   | Действие                                            |
|---------------|-------------|---------------------------------------------------|
| 🟢 GREEN      | Норма      | Нормальная работа                                  |
| 🟡 YELLOW     | Предупреждение     | Лог-алерт + повышение порога обучения              |
| 🔴 RED        | Критично    | Экстренное сохранение + массовая обрезка слабых рёбер            |

## Быстрый старт

### Сборка

```bash
# Требуется GCC + pthread + OpenMP (других зависимостей нет)
make all

# Кросс-компиляция для ARM
make CC=aarch64-linux-gnu-gcc all
```

### Запуск

```bash
# Интерактивный шлюз (рекомендуется)
./build/bin/pivotmind_gateway

# Интерактивный CLI-режим
./build/bin/digital_life
```

Шлюз по умолчанию слушает на `:8080`.

### Примеры API

```bash
# Задать вопрос
curl -X POST http://localhost:8080/ask \
  -H "Content-Type: application/json" \
  -d '{"query":"What is consciousness?"}'

# Скормить обучающий материал
curl -X POST http://localhost:8080/learn \
  -H "Content-Type: application/json" \
  -d '{"text":"Consciousness is the subjective experience produced by neural networks in the brain."}'

# Проверить статус
curl http://localhost:8080/status
```

### Цели сборки

| Команда              | Описание                                |
|----------------------|--------------------------------------------|
| `make all`           | Собрать все цели                          |
| `make gateway`       | Собрать только HTTP-шлюз                    |
| `make digital-life`  | Собрать интерактивную CLI-версию              |
| `make seed-builder`  | Собрать инструмент seed-топологии                   |
| `make batch-learn`   | Инструмент батч-обучения                        |
| `make clean`         | Очистить артефакты сборки                      |

## Известные ограничения

- **Сначала китайский** — посимвольная токенизация естественным образом подходит для китайского; опыт с английским / смешанным вводом ограничен
- **Связность ответа** — ассоциативный путь даёт менее естественный текст, чем LLM (активно итерируемся)
- **Нет GPU-ускорения** — Чистый CPU + pthread + OpenMP
- **Бинарные файлы состояния** — Не кросс-архитектурные (x86_64 и ARM несовместимы)
