## 〇、要解决的问题

手写虚词表（`diffusion.c:27-143`，英文 ~90 词 + 中文 ~70 单字）长期痛点：

1. **静态**：学不到新虚词（网络用语/方言虚词永远不会上榜）
2. **跨路径不一致**：≥4 份独立实现（diffusion 表 / PFE 内联 / TPL_WORDS / pos_hash），互不相同
3. **滤掉实词**：代词（我/你/他）被滤 → 词层拼接缺主语
4. **放回是死路**（第一轮 pro 实锤）：单字输出过滤兜底 = 零收益；学习端超高频单字 = 超级枢纽污染

**目标**：让虚词/功能词类从数据中自然涌现，手写表退化为「种子/先验」——但**不过滤虚词**，让虚词当润滑油、不当引擎。**「类目框架」手写（样本效率），「类目成员」涌现。**

## 一、实测数据（2026-08-14 扫 pivotmind_state.dat，31.5万边 / 15.4万节点）

| 词类 | 代表 | 边数 | 均权 | 最大权 | 特征 |
|---|---|---|---|---|---|
| 虚词 | 是/在/中/为/了/于/个/和 | 386-642 | 0.400 | **0.400** | 全弱边，无 Hebbian 强化 |
| 高频实词（有强边） | 学/生/道/多/国/成/物 | 542-928 | 0.57-0.64 | **1.000** | 有强边！ |
| 高频实词（无强边） | 大/水/小/山/人 | 67-355 | 0.400 | 0.400 | **图结构与虚词同构！** |
| 多字实词 | 时间/苹果/思想/电脑 | 11-145 | 0.5+ | 0.6-0.9 | 有强 Hebbian 边 |
| 异常 | 我 | **5** | 0.432 | 0.960 | 最高频代词近乎孤立 |

**关键结论**：
- 光靠 edge_count / mean_w / 熵**分不开**「是」（虚词）和「大/水/人」（单字实词）——单字实词也是 0.400 全弱边
- 能分开的信号：**位置画像**（是句首句中句尾都出现，大很少句尾）+ **加权实义构词**（大→大学/大海/大人，是→但是/可是但那些组合词自己是功能词）
- 「我」5 边是**被饿死不是被压制**（max_w=0.960 说明边质量极高）：是/在/了 在 QA 语料高频 → 386-642 边；我/你/他 在 QA 语料低频、真正高频的对话路径恰好被滤

## 二、修正版方案（pro 四硬伤修正后）

### 2.1 三类分类器（判定条件全部可计算）

```
虚词 = 位置画像(漂浮型 ∨ 锚定型) ∧ 无强边 ∧ 不参与实义构词
高频实词 = 有强边(max_w>0.5) ∨ 加权实义构词参与度高
普通实词 = 其他
```

**四根轴**：

| 轴 | 量 | 判定 | 实测依据 |
|---|---|---|---|
| ① 位置画像 | 句首率 p0 / 句中率 p1 / 句尾率 p2（**复用 dist_sig[22..23]**，不新增字段） | 漂浮型：p1 居中 ∧ p0>0.15 ∧ p2>0.15；锚定型：p2>0.8（句尾语气/助词）∨ p0>0.8（句首代词/介词） | 「吗/吧/呢」句尾率≈1.0 是虚词不是实词——单标量自由度会误杀，三值画像能抓 |
| ② 无强边 | max_w - mean_w < 0.05 | 虚词全 0.400 弱边；实词有 0.5-1.0 强边 | 区分度好，✅ 可行 |
| ③ 高通用度 | edge_count > 100 | 虚词几百条边 | ⚠️ 代词边数天生低（我=5），需位置/构词轴兜底，阈值待验证 |
| ④ 加权实义构词 | 单字作为**实义组合词**组成部分的加权计数（组合词 max_w>0.5 才计分） | 大→大学/大海 计分；是→但是/可是（全弱边连词）计 0 | naive 计数会把「是」误判实词——必须与组合词自身边权绑定 |

**构词轴实现**：离线周期扫描 `vocab->net` 中所有 `strlen(concept)>3` 的 CJK 节点，检查目标单字是否其子串；组合词有强边（max_w>0.5）才计实义构词。O(nodes × avg_len) 毫秒级，锁外可做。

### 2.2 职责分离（不过滤但用起来，不喧宾夺主）

```
┌────────────────────────────────────────────────┐
│ 学习端：虚词照常建边（不过滤！=连接资本），     │
│   但虚词不参与组合词晋升（"的"不进"的了"）      │
│   ⚠️ 落点：连 cp_tracker_record 一起跳过        │
│   （连 g_single_count 都不累加）——否则虚词高频  │
│   稀释条件概率分母，反向抑制正常组合词晋升       │
├────────────────────────────────────────────────┤
│ 扩散引擎（语义选择器=实词的舞台）：             │
│   虚词不进语义竞争候选——不喧宾夺主              │
├────────────────────────────────────────────────┤
│ 组装器（语法组织者=虚词的舞台）：               │
│   槽位需要时按 POS 取虚词（主语→代词、          │
│   介词短语→PREP、句尾→PART）——用起来           │
├────────────────────────────────────────────────┤
│ 关键词/激活种子：虚词不作为激活种子              │
│   （extract_key_concepts 现有行为保留）          │
└────────────────────────────────────────────────┘
```

**代码落点（学习端职责分离）**：
- `dialog_generate.c:689`：`is_stop_word` 从「整体跳过」拆成「建边不跳过、晋升跳过」——虚词进 `cjk_ids` 参与滑动窗口建边，但打 `is_func[]` 标记
- `dialog_generate.c:706`：`if (is_func[i] || is_func[i+1]) continue;`——虚词**不 record cp_tracker**（连 g_single_count 都不累加）
- `dialog_generate.c:753-773`：滑动窗口建边照常（虚词进 node_ids，连接资本）

### 2.3 分类器落点：必须输出名单（FuncwordSet）

```
is_function_word(w) = 手写硬地板(w) || FuncwordSet.contains(w)
分类器(周期扫描, 锁外) → 输出写 FuncwordSet（conf 滞回 + cap 256）
职责分离(学习端/扩散端/组装器) → 只消费集合，不各自跑分类器
```

**为什么必须集合**（pro 裁定）：可解释性（涌现名单打给人看）/ 滞回稳定性（conf 连续命中 K 次防抖动）/ 性能（周期扫描一次写集合 vs 9 处调用点各自扫边）。

9 处 `is_function_word` 调用点**一字不改**，只改函数体。但注意**调用点语义分两类**：
- 扩散源/语义竞争（:1355/:1383/:975/:1006）→ 虚词**仍过滤**（虚词不当语义引擎）
- 输出端（:1552/:1595/:1629/:1673/:1690）→ 阶段 3 **按 POS 放开**（组装器需要 PRON/PART/PREP 进 word_buf）

### 2.4 手写表终点形态

- **~15 真虚词种子（硬地板，永不删除）**：的/了/是/在/有/不/和/我/你/他/这/那/把/被/对 + 英文 ~15
- **200 词 pos_hash**（cognitive_controller.c:1308）：标注器，组装器用——**不是停用词表，保留**
- **11 类 POS 框架 + 50 词种子**（emergent_pos.c:47-73）：先验骨架
- 成员资格 100% 涌现，0 手写新增

## 四、风险与兜底

| 风险 | 影响 | 缓解 |
|---|---|---|
| 虚词→实词（漏网） | 进活跃集当扩散源，喧宾夺主 | relevance<0.3 过滤 + 度惩罚 + 单字长度过滤（阶段0-2）三层兜底；硬地板永不误判 |
| 实词→虚词（误杀） | 退出扩散，话题缺激活源 | 构词轴专门为此设计；FuncwordSet 滞回 + 诊断日志人工回看 |
| pos_prior 只喂语料不喂对话 | 「我」句首率信号丢失 | 对话前置 hook（auto_learn_concepts 循环 is_stop_word 判断前累积） |
| 虚词 record cp_tracker | 稀释条件概率分母，抑制组合词 | 连 cp_tracker_record 一起跳过（2.2 落点） |
| 锁/性能 | 扫描锁内长持 → 线程堆积（08-07 教训） | funcword_scan 全 O(nodes) 锁外；写集合拿 1 次锁；dshape 累积 O(1)/token 走 node_locks |

**核心兜底原则**：分类器只影响「涌现扩展的那部分虚词」，**手写硬地板（~15 种子）永不撤**。任何阶段误分类只影响硬地板之外的边缘词，不影响核心虚词过滤。
