> 本文档沉淀 TWN 核心设想、当前实现对照、架构评审结论与落地路线。

## 一、核心设想（原始设计）

**基本元素：拓扑图。** 每个拓扑图代表一种知识模态或认知功能：
- 语义拓扑：词语、概念、语义关系
- 视觉拓扑：图像、视觉特征
- 文本拓扑：故事、叙事、上下文
- 情绪拓扑：情感、价值、偏好
- 以及其他认知维度的拓扑……

子拓扑归属于主拓扑的嵌套，形成「主拓扑—子拓扑」的层级结构。

**跨拓扑边与递归拓扑。** 子拓扑之间通过跨拓扑边连接。当两个节点被跨拓扑边连接得越来越紧密时，形成**递归拓扑**——一个子拓扑内部嵌套着融合了多种模态的子拓扑。

以「塞翁失马」为例：
- 词汇拓扑里它是一个词
- 通过跨拓扑边连接到文本拓扑里的具体故事
- 再通过跨拓扑边连接到情绪拓扑里的感悟和情感
- 三条跨拓扑边足够紧密后，「塞翁失马」变成一个递归拓扑——融合词义、故事、感悟、情感，成为高阶概念的整体

**运行逻辑：两级求解。**
- **第一步 · 局部最优解**：每个子拓扑独立计算自己的局部最优解（节点置信度/权重/效价；边权重/激活/效价/好奇度；跨拓扑影响），同时受其他子拓扑约束
- **第二步 · 全局最优解**：子拓扑将局部最优解上交主拓扑；主拓扑结合推理拓扑与意图分析拓扑，整合出全局最优解作为系统最终输出

## 二、实现对照（2026-08-13 现状）

### 2.1 基本元素

| 设想 | 实现 | 程度 |
|---|---|---|
| 语义拓扑 | `TOPO_VOCABULARY` + `TOPO_SEMANTIC` | ✅ 100% |
| 视觉拓扑 | `TOPO_VISUAL` + visual_cortex 脑区 | ⚠️ 50%（骨架在，未接视觉输入）|
| 文本/叙事拓扑 | 拆为 `syntax`（句式）/ `context`（上下文）/ `template`（模板）| ✅ 80%（分化）|
| 情绪拓扑 | `TOPO_EMOTION` + amygdala/cingulate | ✅ 100% |
| 其他模态 | 增量长出 `domain`/`pragma`/`culture`/`concept` | ✅ 超预期 |
| 主拓扑-子拓扑层级 | `MasterTopology` → 11 子拓扑（12 层枚举）| ✅ 100% |
| **跨拓扑边** | `CrossTopologyLink` + cross_adj O(1) 索引 | ✅ **100% 原样实现** |
| **递归拓扑** | `TOPO_CONCEPT` 词晋升（字→词绑定）为雏形；**无跨模态融合/嵌套结构** | ⚠️ ~30% |

### 2.2 运行逻辑

| 设想 | 实现 | 程度 |
|---|---|---|
| 局部最优解 | diffusion 引擎每层独立 spread；节点 activation/weight/valence；边 weight；curiosity 采样 | ~75%（边效价/边好奇度参与不完整）|
| 全局最优解 | IdeaArena 5D 竞争（语义/模板/情绪/长度/多巴胺，权重 `{0.30,0.25,0.15,0.15,0.15}` 手调）| ~60%（整合有，上交机制未按设想建）|

## 三、架构评审结论（2026-08-13，pro 模型批判性评审）

### 3.1 关键代码事实

- **co-activation 已存在且在线**：`CrossTopoHitRecord.hit_count`（2048 槽开放寻址表），`master_record_cross_hit` 在 `topology_walk_cross`/dream_engine 调用，`master_process_cross_hits(threshold=5)` 自动建跨边——**共现 ≥5 次建跨边已是活机制**
- **多巴胺学习已有模板**：`pfe_update_strategy_weights(mode, reward)`（EMA 更新 + 归一化 + 持久化）——只作用在 PFE 6 推理模式，未作用 IdeaArena 5D
- **递归拓扑已存在**：概念拓扑的词节点 = 绑定两个字的整体——「词」本质就是同模态递归节点
- **引用范式已定**：`ConceptNode.concrete_nodes[]`（引用数组）+ compound 词节点 cross-link 回指——「引用，绝不复制」

### 3.2 提案修正

1. **递归触发条件：AND 硬阈值 → 评分制**
   `binding_score = α·跨模态边强度 + β·co-activation 归一 + γ·路径复用频率`，超分排序晋升（qsort 截断，复用 compound_promote 模式）——避免 AND 极端稀疏
2. **三角闭包 → 路径复用**：「塞翁失马」的本质是跨模态路径成环，三角只是路径长度=3 的特例；`PathFrequencyTable`（freq_table）已存在——递归拓扑应从**高频跨模态路径**涌现
3. **「求最优解 vs 扩散+竞争」是假二分**：系统已是扩散+竞争（argmax 内嵌），真问题是**竞争单元碎片化**——没有整体单元参与竞争
4. **数据结构：引用，绝不复制**——复制引爆一致性灾难（激活同步/遗忘/删节点/锁序双写）

### 3.3 独立洞见（合流点）

> **递归拓扑不需要新结构，它已经存在——词节点就是绑定两个字的递归节点。病根是：递归只发生在同模态（字→词），且绑定节点从未进入竞争。**

- A（递归触发）与 B（竞争升级）是同一枚硬币：让绑定节点作为「整体候选」进入扩散走边与 IdeaArena 竞争（激活 → 顺反向 cross-link 展开子图 = pattern completion，海马体索引绑定范式）
- **红线审视偏了**：5D 权重手调是「权衡先验」（类脑可接受）；真正最该被涌现替代的是 diffusion 的 **stopword 表 + VerbValency 配价表**（「吃/喝/看带宾语」这种结构预置）

### 3.4 风险提示

任何新结构须沿 `rwlock → net.mutex → node_locks` 三级锁序；绑定引用数组的 realloc 必须全程写锁（本库两次事故——v0.5.14 死锁、SIGSEGV——都是并发 realloc 悬垂/读锁升级翻的车）。

## 四、落地路线（3 步）

| 步 | 做什么 | 验证什么 |
|---|---|---|
| **1. 绑定结构（造单元）** | `ReasoningNode` 加 `(topo_id,node_id)[]` 绑定引用；`autonomic_compound_consolidate` 泛化为 `autonomic_binding_consolidate`（字对 → 跨拓扑节点组），评分制晋升，三级锁序 | 涌现跨模态绑定节点（「塞翁失马」绑定词/文本/情绪），无死锁/悬垂 |
| **2. 激活路径（让单元能用）** | 绑定节点进扩散走边：激活 → 反向 cross-link 子图整体激活（复用现有跨边 spread）| 走边走到绑定节点并展开子图；`semantic_coherence`（topo_eval.c）上升 |
| **3. 竞争升级 + 权重学习（让单元能赢）** | IdeaArena 候选升级为绑定整体；5D 权重 `static const` → 可学习（pfe 式 EMA + 内在奖励闭环）| 对话从碎片拼接 → 整体概念；权重随语料漂移持久化；回归不退化 |

### 奖励信号（涌现纯度排序）

1. **内在奖励**（首选）：新颖性（explore_rate）、预测误差/压缩、子目标完成度——自产，不需外部标签
2. **胜者归因**（次选）：winner 各维度贡献（本地 SHAP 式）+ 后续连贯性反传
3. **PFE satisfaction reward**（沿用）：与 `pfe_update_strategy_weights` 同源，避免两个闭环打架

## 五、认知科学对应

| TWN 概念 | 认知科学对应 |
|---|---|
| 递归拓扑 / 绑定节点 | 海马体索引绑定（Teyler & DiScenna）；互补学习系统（McClelland/O'Reilly）|
| 绑定节点激活展开子图 | pattern completion（模式补全）|
| 扩散 + 竞争 | 全局工作空间理论（GW）；基底节多巴胺门控行动选择 |
| 跨模态路径成环 → 高阶概念 | 情景记忆绑定；概念层级（concrete → abstract）|
| 好奇度采样 | 主动推理/自由能最小化（Friston）|

## 六、遗留问题（诚实清单）

1. **递归拓扑的跨模态融合未实现**——绑定结构（步 1）未落地
2. **视觉拓扑未通电**（mcbody 计划中）
3. **边效价/边好奇度未完整参与扩散**（当前主要走 weight）
4. **意图分析拓扑未建**（红线：从统计涌现，prefrontal 做分解代替）
5. **stopword 表 + VerbValency 配价表仍是结构预置**（红线盲区，待涌现替代）
6. **推理拓扑的「上交-整合」机制**未按设想建（IdeaArena 竞争代替）
