# 018-B 修复报告：BackgroundClock 后台时钟循环实施

> 日期: 2026-05-28 | 关联审查: 018-A

## 已修复项

### P1: 系统缺乏时间连续性 — 新增 BackgroundClock 模块

**改动文件**: `include/background_clock.h` (NEW), `src/background_clock.c` (NEW)

**改动内容**:
- 新建独立的 `BackgroundClock` 模块，遵循 `ActiveLearner` 的 `create → start → stop → destroy` 模式
- 独立 `pthread` 线程，每秒 tick 一次，与对话主线程并行运行
- 结构体包含：master 拓扑引用、memory 系统引用、cognitive_state 引用、线程控制、可配置参数

**BackgroundClock 结构体**:
```c
typedef struct BackgroundClock {
    MasterTopology* master;          // 拓扑网络（持读锁访问）
    MemorySystem*   memory;          // 记忆系统（内部有互斥锁）
    CognitiveState* cognitive_state; // 认知状态（低竞争，无需锁）
    pthread_t thread;                // 时钟线程句柄
    volatile int is_running;         // 运行标志
    int   tick_interval_ms;          // 时钟间隔（默认 1000ms）
    int   tick_count;                // 累计 tick 数
    float decay_per_tick;            // 每tick衰减率（默认 0.97）
    float spontaneous_prob;          // 自发激活概率（默认 0.0001）
    float spontaneous_strength;      // 自发激活强度（默认 0.15）
    int   consolidate_every_n_ticks; // 记忆巩固间隔（默认 10）
} BackgroundClock;
```

### P2: 激活值缺乏自动衰减 — 实现全拓扑激活衰减

**改动文件**: `src/background_clock.c` — `decay_sub_topology()`

**改动内容**:
- 每 tick 遍历所有 9 层子拓扑的所有节点
- 持 `pthread_rwlock_rdlock` 读锁执行（只修改 float，不修改拓扑结构）
- `node->activation *= 0.97f`（每秒衰减 3%）
- `activation < 0.01f` 时归零（避免无限小的浮点尾数）
- 计算：9 × ~max 10000 nodes ≈ 90000 次浮点乘法，预计 < 5ms

---

### P3: CognitiveState 缺乏内稳态回归 — 实现全局认知状态漂移

**改动文件**: `src/background_clock.c` — `drift_cognitive_state()`

**改动内容**:
- 每 tick 无锁更新 `CognitiveState` 的所有数值字段
- Drive/Emotion 向基线 EMA 回归（keep=0.995, pull=0.005, 时间常数~200秒）:
  ```
  drives[i]   = drives[i]   × 0.995 + baseline[i] × 0.005
  emotions[i] = emotions[i] × 0.995 + baseline[i] × 0.005
  ```
- Valence 向中性 0 缓慢回归: `valence *= 0.998`
- Explore rate 由效价调制: `explore_rate = 0.5 + valence × 0.5`
- 默认基线: curiosity=0.5, hunger=0.3, social=0.5, comfort=0.5, pleasure=0.5, pain=0.1, security=0.6

**线程安全**: x86 上对齐浮点数写入天然原子，且竞争窗口极小（对话线程每轮至多修改一次态状态）

### P4: 新增自发激活 — 模拟"念头涌现"

**改动文件**: `src/background_clock.c` — `spontaneous_activate()`

**改动内容**:
- 每 tick 按期望值计算自发激活次数: `total_nodes × 0.0001`
- 随机选择子拓扑和节点，注入 0.1~0.2 的弱激活
- 按期望值随机而非每节点 `rand()`（避免 90000 次/tick）
- 激活上限钳制为 1.0

---

### P5: 记忆巩固 tick — 周期性 STM→LTM 迁移

**改动文件**: `src/background_clock.c` — `clock_loop()`

**改动内容**:
- 每 10 个 clock tick（~10 秒）调用一次 `memory_consolidate(clock->memory)`
- `memory_consolidate()` 内部已有 `pthread_mutex_t`，无需额外加锁
- 非每 tick 调用：避免 90000 节点遍历后再做一次 O(n²) 巩固

## 设计原则

- 坚持生物启发路线，拒绝 LLM 思路（GPT 的无状态 token 预测不需要时间连续性）
- 赫布在线学习，不引入反向传播
- 复用 `MasterTopology.rwlock` 读锁（读锁间不互斥，不影响前台）
- 遵循 `ActiveLearner` 的 create/start/stop/destroy 线程模式
- 数字生命的核心哲学：**生命不是一个状态，而是一个持续过程**
