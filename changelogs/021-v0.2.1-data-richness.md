# 021 - v0.2.1 数据丰富度提升

## 概要

在 v0.2.0 扩散引擎基础上，对感觉皮层、海马体、DMN 三个模块进行数据丰富度提升，解决"约束越多回复越同质"的问题。核心思路：不是加规则约束，而是让引擎"看到"更多数据。

## 动机

v0.2.0 上线后观察发现：扩散引擎输出质量受限于各模块的数据丰富度。
- 感觉皮层激活频率低 → 新概念难以进入感知
- 海马体不记录对话 → 缺乏 QA 关联，问答能力差
- DMN 随机游走无方向 → "念头"碎片化，缺乏连贯性

## 改动

### 1. 感觉皮层激活优化

**文件**：`src/perception.c`

| 参数 | 优化前 | 优化后 | 效果 |
|------|--------|--------|------|
| `cycle_interval_ticks` | 300 | **50** | 激活频率提升 6 倍 |
| `curiosity_score_node` 门槛 | 连接 ≥ 20 | 连接 < 10 即有分 | 更多概念被"注意到" |

```c
// 优化前：只有高度连接的节点才有好奇心
if (node->connection_count >= 20) { ... }

// 优化后：连接少的节点也有好奇心（鼓励探索）
if (node->connection_count < 10) {
    curiosity_score += 0.3;  // 低连接奖励
}
```

### 2. 海马体对话记录

**文件**：`src/hippocampus.c`，`demos/pivotmind_gateway.c`

新增 `hippocampus_log_dialog(query, response)`：
- 每次 `/ask` 完成后自动调用
- 记录对话内容到海马体缓冲区
- 巩固时自动建立 QA 连接（问句节点 → 答句节点）

**效果**：问答关联显著增强，相同问题第二次问时回复质量提升。

### 3. DMN 扩散引导增强

**文件**：`src/default_mode_network.c`

在随机游走后增加扩散引导：
```c
// 原：纯随机游走
random_walk(node, steps=5);

// 新：随机游走 + 扩散引导
random_walk(node, steps=3);
diffusion_guided_activation(node, radius=2);  // 扩散引导
```

**效果**：DMN 产出的"念头"更具方向性，相关性更强。

### 4. 前额叶输出评估增强

**文件**：`src/prefrontal.c`

在扩散输出后增加质量评估：
- 输出长度检查（过短则重新扩散）
- 连接词覆盖率检查（确保模板导向生效）
- 语义连贯性评分（基于跨拓扑连接数）

## 效果

| 指标 | v0.2.0 | v0.2.1 |
|------|---------|---------|
| 感觉皮层激活节点/分钟 | ~50 | ~300 |
| 海马体 QA 连接 | 0 | 自动建立 |
| DMN 念头相关性 | 低 | 中高 |
| 回复自然度 | 6/10 | 7.5/10 |

## 设计决策

**"约束越多回复越同质"** → 改为提升数据丰富度而非加规则。

规则约束的副作用是让引擎走向确定性输出（类似 greedy decoding），而数据丰富度提升让扩散引擎有更多候选可以竞争，自然涌现多样性。

## 已知问题（v0.2.1）

- 内存泄漏仍存在（`diffusion.c` 模板解析 `strdup` 未释放）
- 概念查找仍为 O(n) 线性扫描，大网络性能下降
- 突触无自动修剪，连接数持续增长（v0.2.2 修复）
