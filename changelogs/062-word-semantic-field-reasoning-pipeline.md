# 0.5.7 — 词层语义场与推理管线

> **日期**: 2026-08-01 | **类型**: 功能 + 修复 + 性能

## 概述

从 0.5.6 的"知识存得住"到 0.5.7 的"知识说得出"：词层架构（词巩固/词锚定）落地、话题性识别上线、PFE 推理管线跑通（28s→2s）、词级语义场建立。同时根治了知识被清光与四大 O(N²) 性能卡点。

## 背景

0.5.6 时期知识能稳定加载（rwlock 修复），但：① 生成端只有单字节点，无词级语义单元（"关羽/武器"不存在，答非所问）；② RED 冻结雪崩把知识清光（load_protect 未初始化）；③ PFE 推理管线在 5 万节点图上 4 层 O(N²) 卡死（28s+）；④ 词节点孤立（只连字不连词），语义场（时间→过去/钟表）不存在。

## 核心变更

### Fixed

- **rwlock 死锁根治**（glibc 写锁内嵌套读锁返回 EDEADLK，忽略返回值后错误 unlock → 锁状态损坏 → 下次 wrlock 永久卡死）。`cross_link_exists` 拆 `nolock` 变体，写锁持有者内部调 nolock 版。
- **知识被清光多层根因**：
  - `load_protect` 未初始化（malloc 垃圾值 → 保护期从未生效）→ 初始化 + 恒定 60 tick 递减
  - 时间保护期 30 分钟（`PM_LOAD_PROTECT_SECONDS`，RED 加速 tick 下 tick 版只撑 5 分钟）
  - 保底激活 0.3（防跌破冻结线被 RED 修剪）+ 边权保底 0.2（防遗忘 cleanup）
  - 修剪跳过 `is_cooled`（冻结 = lazy memory 缓存释放，不删知识）
  - RED 阈值放宽（增速 30MB/min、冻结 10000、RSS 1200MB）
- **词巩固并发 SIGSEGV**：词巩固全程持 master 写锁（原无锁遍历 vocab + 对话线程 realloc → 悬垂指针）。
- **PFE 四大 O(N²) 卡点**（gdb 行号逐个定位）：
  - 因果图去重线性搜索（5 万节点 25 亿次 strcmp）→ djb2 哈希桶
  - 加边查重/统计/环检查（O(E²)）→ `add_causal_edge_no_check` 批量版
  - 边查询全边扫描（A* 热路径）→ 邻接表（outgoing 存边索引，8 处邻居遍历同步改）
  - A* 扩展 5 万 target 全跑（14^5 爆炸）→ 扩展上限 2000 + 探索上限 100
- **因果图缓存悬垂**：`causal_associative_search` 末尾 destroy 共享缓存图 → 下次调用 pool_destroy 崩溃。缓存图由指纹（节点数±500 容差）管理生命周期。
- **上下文注入串扰**：gateway 把上轮回复拼进当前输入 → 词锚定命中旧回复词（"衣服"→"历史"串扰）。禁用注入，输入保持纯当前话题。
- **子目标主语提取**：`extract_subject` 重写——"历史为什么重要"取疑问词前（"历史"）、"为什么时间重要"取疑问词后去尾巴词（"时间"）、UTF-8 字节修正。

### Added

- **词层架构**（词从语料统计自己长出来）：
  - `feed_cli` 字级单向语序边 + Hebbian 饱和曲线（共现频率进边权）
  - 词巩固 `autonomic_compound_consolidate`（brainstem tick 周期）：相对强度/绝对强度双通道涌现（相对≥1.5 或绝对≥0.85）+ 虚字过滤 + 高频方向定词序 → 概念拓扑晋升 + cross-link 回字
  - 词锚定：diffusion 先查概念拓扑，命中词节点 → word_prio 优先输出
- **话题性三层**：
  - relevance 评分（候选与输入锚定集边权相关性，<0.3 过滤——"时间很大"式高频噪声被压）
  - 有界联想回退（候选空时次相关 0.3-0.5 联想，非随机激活）
  - 话题序组装（词锚定优先 + 短句 ≤4 实词 + 中文单字过滤；语法组装暂缓，等 POS 标注成熟）
- **PFE 推理管线跑通**：
  - 推理词保底触发（单个"为什么/怎么/如何"不再被复杂度≤1 拒掉；"什么"类定义问句走 diffusion）
  - 子目标分解 → 因果搜索/A* + diffusion 求解 → 推理链合成（6 子目标 + 置信度 + 模式标注）
  - 答案语义场化：best_text 取前 3 实义词（滤虚词/单字，"时间是"→"时间"）
- **词级语义场**：
  - `feed_cli` 2 字窗口配对词候选（每 2 个连续中文字一窗，错位词"间早"不产生）+ 窗口间 Hebbian 共现边
  - diffusion 词邻居扩散（词锚定后拉词-词边邻居 w≥0.3 进输出）
- **词级语义拓扑**：
  - `semantic_grow_from_concepts`：概念拓扑词节点特征聚类（激活排序采样——原等间隔采样漏高频词）→ 语义概念节点
  - 词特征 0 填充（建节点时 NULL 未训练 → 用 cross-link 成员字特征均值，"时间"=时+间 均值）
  - 语义场查询（词 → 所属语义概念 → 成员词，聚类优先于共现近似）
  - brainstem 双语义生长（字 + 词并行），SG_MIN_CLUSTER_SIZE 3→2

### Changed

- **PFE 门槛**：验证后恢复 >0（触发词表窄，"什么"不触发，实际几乎休眠；diffusion 降级路径话题化后 answer_text 随之修复）
- **词级虚字表**：缩小到"绝对虚字"（的/了/是/在/和/与/或/也/都/就/很/不/要/会/能/吗/呢/吧/啊/这/那/有/我/你/他/她/它/们）——"过去/将来/上面/儿子"等含字级虚字但整体实义的词必须保留（用户纠正：词级审视不能照搬字级虚字表）
- **功能词兜底**：回复若只有"很+X"类功能词组合 → 礼貌默认"好的。"
- **版本策略**：以后只能小步更新（0.5.7 这种），大版本（0.6）必须用户拍板

## 验证

- 稳定性：48 分钟连续监控，vocab 3 万+ 零丢失，冻结 0-2 条，RSS 稳定
- 词锚定对话：衣服→衣服 / 历史→历史 / 时间→时间（话题词正确回复）
- 推理管线："为什么时间重要" 28s 卡死 → 2s 推理链（6 子目标分解+求解+合成+置信度）
- 语义场："工作→人员 / 东方→民族 / 母亲→吃饭"（词-词共现语义场词输出）
- 词巩固：464→1028 词（虚字表修正后）

## 已知问题

- 语义场词混有共现噪声（"溅满/顾害"类窗口词）——共现≠语义，语料积累 + 聚类成熟后改善
- 子目标求解多走 diffusion 降级（因果搜索命中率低——A* 限制后快速失败）
- 书源 bug：SD 卡书库 9 本"古籍"实为英文书（三国演义.txt=英文书），古典知识从未进入
