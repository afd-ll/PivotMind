# 审查报告 001A — 字符串安全 + 原子操作 + 编码统一

> 配对修复报告：001B
> 日期：2026-05-25

## 审查目标

全面审查 src/ 目录的安全隐患：strcpy/strcat 缓冲区溢出、volatile 竞态条件、编码不一致。

## 发现问题

### P0：23 处 strcpy/strcat 无边界检查
- `dialog_system.c`: 17 处 strcat 拼接回复文本（4096 字节固定缓冲）
- `chinese.c`: 2 处 strcpy 繁简转换
- `vocab.c`: 3 处 strcpy 词表解码
- `causal_reasoning.c`: 1 处 strcpy

### P1：thread_pool.c volatile 非原子
`volatile int running/shutdown` 不保证多线程可见性，需改 `atomic_int`。

### P2：src/ 54 个 .c 文件编码混杂
部分 GBK、部分 UTF-8，导致中文注释乱码。

### P3：test_runner.c 的 prev_failed 作用域错误
局部变量被宏跨作用域引用。

## 改动建议

| 优先级 | 文件 | 改动 |
|--------|------|------|
| P0 | dialog_system.c 等 | strcpy→strncpy, strcat→strncat |
| P1 | thread_pool.c | volatile→atomic_int |
| P2 | src/*.c | 统一 UTF-8 |
| P3 | test_runner.c | prev_failed→全局变量 |
| P3 | Makefile | -D_USE_MATH_DEFINES 统一到 CFLAGS |
