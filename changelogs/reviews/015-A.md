## 一、发现问题

### P0：extract_ordered_chars 换行符编码损坏 🔴

**位置**：`src/autonomic_learner.c:231-233`

```c
if (*p == ' ' || *p == '	' || *p == '
' || *p == '
') {
```

`\t`、`\n`、`\r` 的转义序列在 code_execution 写入时被展开为实际的控制字符，导致函数体跨多行且字符比较失效。

**影响**：空格/制表符/换行符的跳过逻辑完全失效。
