# 0.4.14 — 扩散引擎 UTF-8 字符窗口匹配

> **日期**: 2026-07-10 | **类型**: 修复

## 概述

扩散引擎的滑动窗口原本按字节数（`win=3/2/1`）截取输入子串去匹配拓扑节点，UTF-8 中文每字 3 字节，导致永远只能匹配到单字，多字词节点（"人工智能" 12字节/4字）永远无法激活。

## 核心变更 / 修复内容

`src/diffusion.c` — `diffusion_generate()`:

- **问题**: `for (int win = 3; win >= 1; win--)` 中 `win` 是字节数。中文每字 3 字节，`win=3` 只抓到 1 个字，"人工智能"（12 字节/4 字）无法匹配。
- **表现**: PMI 已涌现 "人工智能"(7边)、"神经网络"(44边)、"机器学习"(14边) 等有效多字词节点，但扩散只激活到单字 token（"人""工""智""能"），这些单字在拓扑中不存在节点，扩散走不出孤岛，输出 `(无回应)`。
- **修复**: 先建立 UTF-8 字符位置数组，窗口按**字符数**滑动（5→4→3→2→1 字），按字符边界截取子串去匹配。
- **影响范围**: 仅 `diffusion.c` 一处改动。不改分词器、不改 PMI 管线。

效果对比：

| 输入 | 修复前 | 修复后 |
|------|--------|--------|
| `什么是人工智能` | 激活: 是 人 工 智 能（5 单字，全无效） | 激活: 人工智能(7边) |
| 回复 | `(无回应)` | `人工智能` |

## 改动文件

| 文件 | 变更 |
|------|------|
| `src/diffusion.c` | 字节窗口 → 字符窗口（+15 行） |
