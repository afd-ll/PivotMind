# v0.3.0 — 推理架构：前额叶执行器 + 想法竞争竞技场

**日期**: 2026-06-20  
**版本**: 0.3.0 (MINOR 升级 — 功能新增，向前兼容)

---

## 概述

v0.3.0 是 PivotMind 架构中**推理能力**的首次系统性引入。在此之前，系统拥有完整的感知→记忆→联想→生成闭环（v0.2.x），但推理始终是一个缺口——所有路径都是单次联想，缺乏目标分解、子目标调度、多候选竞争和反思验证。

本次新增两个子系统，对应于人类大脑中的两个关键功能：

| 生物对应 | 系统模块 | 职责 |
|---------|---------|------|
| 背外侧前额叶 (DLPFC) | `PrefrontalExecutive` | 维持目标、任务分解、子目标调度、冲突检测、综合输出 |
| 基底节 + 全局工作空间 | `IdeaArena` | 多候选想法竞争选择、五维评分、侧抑制、多巴胺调制 |

## 架构设计

### 1. PrefrontalExecutive — 推理编排引擎

**核心原则**: PFE 不自己走路、不自己评估。它只做编排——将复杂推理任务拆分为多个小任务，每个小任务复用现有的 `CognitiveController` 标准流水线。

**推理模式**:

| 模式 | 触发关键词 | 分解策略 |
|------|----------|---------|
| `PFE_MODE_DIRECT` | 无 (默认) | 单目标，走现有联想路径 |
| `PFE_MODE_DECOMPOSE` | 为什么/原因 | 查定义 → 查特征 → 因果链 |
| `PFE_MODE_COMPARE` | 比较/区别/不同 | 提取A属性 → 提取B属性 → 对比 |
| `PFE_MODE_HOWTO` | 怎么/如何 | 前置条件 → 操作步骤 |
| `PFE_MODE_ABDUCE` | 如果/假设 | 基线状态 → 推测连锁反应 |
| `PFE_MODE_ANALOGY` | 类比/类似 | 源结构 → 目标结构 → 映射 |

**主推理流程**:
```
pfe_reason()
  ├─ 阶段1: pfe_assess_complexity() — 复杂度评估 (0/1/2)
  │   └─ 简单(0) → 直接联想，快速返回
  ├─ 阶段2: pfe_decompose_question() — 任务分解为子目标序列
  ├─ 阶段3: pfe_solve_subgoal() × N — 逐个求解（含依赖注入）
  ├─ 阶段4: pfe_detect_conflicts() → pfe_resolve_conflicts() — 冲突回溯
  └─ 阶段5: pfe_synthesize_answer() — 综合输出
```

### 2. IdeaArena — 想法竞争竞技场

**五维竞争空间**:

| 维度 | 含义 | 权重 | 硬门槛 |
|------|------|------|--------|
| Goal Fit | 是否在回答用户问题 | 30% | 0.45 |
| Consistency | 与已有知识一致 | 25% | 0.35 |
| Novelty | 新颖/非老生常谈 | 15% | 0.05 |
| Valence | 情绪效价 | 15% | -0.50 |
| Composability | 可与其他想法拼接 | 15% | 0.10 |

**竞争算法**:
```
arena_compete()
  ├─ 杏仁核调制: explore_rate → novelty_boost + inhibition
  ├─ 多轮竞争:
  │   ├─ arena_compete_round()
  │   │   ├─ 硬门槛淘汰: 任一维度不达标 → 出局
  │   │   ├─ 侧抑制: 相似候选互相削弱（重叠>0.4 + 对方更强 → 我被抑制）
  │   │   ├─ 多巴胺调制: explore_rate高 → 新颖奖励大，inhibition低
  │   │   └─ 收敛检测: 最高-次高 > threshold → 结束
  │   └─ (loop until converge or max_rounds)
  └─ arena_pick_winner() → 选最高激活者
```

**杏仁核探索/利用调制**:
- `explore_rate` 高 (体验差) → `novelty_boost` 大 (0.05~0.5), `inhibition` 小 (0.5~0.8)
- `explore_rate` 低 (体验好) → `novelty_boost` 小, `inhibition` 大

**胜者反馈回流**:
- 胜者路径节点 → `confidence` EMA 上升 (α=0.05)
- 被抑制候选 → 路径节点 `selection_count` 略微降低
- 硬门槛淘汰候选 → 矛盾边 `motivational_bias` 降低 (Phase 2)
