# Changelogs

本目录记录 PivotMind 项目的所有改动。格式: `NNN-简短描述.md`

## 编号规则

- 三位数字编号，从 001 开始
- 每个改动独立一个文件

## 模板

```markdown
# CHANGELOG #NNN

> 日期: YYYY-MM-DD
> 类型: [修复/新增/重构/清理/文档]
> 关联报告: reports/XXX-xxx.md (如有)

## 改动摘要

简述做了什么。

## 具体改动

- 文件A: 说明
- 文件B: 说明

## 影响范围

列出受影响的模块。
```
