# 016 - v0.2.0 大脑架构重构 — 10 脑区建模

## 概要

将玄枢从**单模块走边引擎**重构为**10 脑区协同架构**，每个脑区对应生物大脑的一个功能模块，各司其职、通过丘脑统一调度。这是玄枢从"工程原型"走向"脑启发系统"的里程碑。

## 动机

v0.1.x 时期，玄枢的核心逻辑集中在 `dialog_process()` 一个函数里：分词→走边→拼回复，全部耦合。随着功能增加（海马体记忆、DMN 自发念头、感觉皮层输入），单文件架构已无法维护。

**核心理念**：大脑不是一块 FPGA，而是多个功能模块通过丘脑调度协同工作。玄枢应镜像这一结构。

## 改动

### 新增 10 个脑区模块

| 脑区 | 文件 | 职责 |
|------|------|------|
| **丘脑** Thalamus | `thalamus.h/c` | 输入调度中枢，门控子系统（决定哪些输入可以激活哪些脑区） |
| **脑干** Brainstem | `brainstem.h/c` | 心跳时钟（1秒tick），昼夜节律，激活衰减，全局后台循环 |

| **DMN** DefaultModeNetwork | `dmn.h/c` | 默认模式网络，无人交互时的自发念头，创造力来源 |

## 各脑区详解

### 丘脑（Thalamus）—— 调度中枢

丘脑是"网关"，所有输入先到丘脑，再由丘脑决定分发到哪些脑区：

```c
// 门控子系统：决定输入能否激活对应脑区
int thalamic_gate(InputSignal* sig) {
    if (sig->type == INPUT_DIALOG) {
        // 对话输入 → 激活前额叶 + 海马体 + 感觉皮层
        activate_brain_region(PREFONTAL);
        activate_brain_region(HIPPOCAMPUS);
        activate_brain_region(PERCEPTION);
    } else if (sig->type == INPUT_CURIOSITY) {
        // 好奇心驱动 → 仅激活感觉皮层
        activate_brain_region(PERCEPTION);
    }
    // ...
}
```

### 脑干（Brainstem）—— 心跳时钟

原 `background_clock.c` 迁入，并扩展为完整的"生理时钟"：

| 行为 | 频率 | 说明 |
|------|------|------|
| 激活衰减 | 每 tick | `node->activation *= 0.97` |
| 自发激活 | 每 tick | 按期望值随机注入弱激活 |
| 状态漂移 | 每 tick | drive/emotion 向基线 EMA 回归 |
| 记忆巩固 | 每 10 tick | STM→LTM 迁移 |
| **昼夜节律** | **新增** | 模拟生物昼夜，低活跃期触发梦境 |

### 前额叶（Prefrontal）—— 生成 + 监控

拆分为双组件：

- **DLPFC**（背外侧前额叶）：`diffusion_generate()` 调用，多层扩散生成回复
- **ACC**（前扣带回）：`output_quality_assess()`，监控输出质量，过低时触发重新生成

### 海马体（Hippocampus）—— 记忆巩固

- 对话记录：`hippocampus_log_dialog(query, response)`
- 记忆巩固：定期将近期对话建立 QA 连接
- **联网联动**（新增）：巩固时触发联网搜索，补充外部知识

### DMN（Default Mode Network）—— 自发念头

无人交互时自动运行，产生"念头"：

```c
// 原：纯随机游走，念头碎片化
random_walk(node, steps=5);

// 新：随机游走 + 扩散引导
random_walk(node, steps=3);
diffusion_guided_activation(node, radius=2);
```

### 感觉皮层（Perception）—— 自主语料输送

**新增核心能力**：不依赖外部输入，自主从语料库抓取内容"感知"世界：

```c
// 好奇心驱动：低连接节点被"注意到"
if (node->connection_count < CURIOSITY_THRESHOLD) {
    curiosity_score += 0.5;
}
// 感知周期：每 50 tick 主动输送一批语料
```

### 布罗卡（Broca）—— 语言产出

确保输出符合语法和流畅度要求，是输出前的最后一道质量关卡。

### 小脑（Cerebellum）—— 资源平衡

系统级优化：监控 CPU/内存使用，动态调整各脑区运行频率，防止资源耗尽。

### 网状结构（Reticular）—— 注意力过滤

防止过度激活：当同时激活节点数超过阈值时，按注意力权重过滤，只保留最重要的激活路径。

### 大脑缓存（NodeCache）—— 热点加速

缓存高频访问的概念节点，避免每次都走哈希表/BFS：

```c
// 热点判断：最近 100 tick 内被访问超过 10 次
if (access_count(node, last_100_ticks) > 10) {
    node_cache_put(node);
}
```

## 新增：brain_state.dat 状态文件格式

原状态文件为顺序存储，加载时需全部读入。新格式支持**索引式随机访问**：

```
brain_state.dat:
[ header: magic + version + index_offset ]
[ node_data: 紧凑二进制存储 ]
[ index: node_id → file_offset 映射 ]
```

**效果**：加载时可直接 `seek` 到目标节点，大状态文件加载速度提升 5-10 倍。

## 网关重构（pivotmind_gateway.c）

`demos/pivotmind_gateway.c` 从 ~50 行扩展为 ~800 行，**集成 10 脑区调度**：

```c
// 请求处理流程（重构后）
POST /ask:
    1. thalamus_dispatch()        // 丘脑调度
    2. perception_feed_input()    // 感觉皮层感知
    3. prefrontal_generate()      // 前额叶生成（扩散引擎）
    4. broca_smooth_output()      // 布罗卡语法校验
    5. hippocampus_log_dialog()   // 海马体记录
    6. return reply

POST /learn:
    1. thalamus_dispatch()
    2. perception_feed_input()
    3. hebbian_learning()        // 赫布学习
    4. hippocampus_consolidate()  // 海马体巩固
```

## 设计决策

### 为什么是 10 个脑区，不是更多或更少？

参考生物大脑的主要功能分区，同时考虑工程可实现性。10 个脑区覆盖了：
- **输入**：丘脑、感觉皮层
- **生成**：前额叶、布罗卡
- **记忆**：海马体、DMN
- **调控**：脑干、小脑、网状结构、NodeCache

每个脑区都有明确且不可替代的职责，避免过度拆分导致调度开销过大。

### 丘脑为什么是调度中枢？

生物大脑中，丘脑是"中继站"，几乎所有感官输入都先到丘脑再分发。玄枢沿用这一设计，使输入路由逻辑集中可维护。
