# 0.2.1 — 多层扩散引擎

> **日期**: 2026-05-31 | **类型**: 新增

## 概要

用多层扩散引擎（`diffusion_generate`）全面替换走边引擎（`dialog_process`），使玄枢从"贪心选边"升级为"多候选竞争输出"。同时引入模板导向连接词插入，回复自然度显著提升。

## 动机

走边引擎基于局部贪心策略，每次只沿当前节点权重最高的边前进，导致：
1. **路径短**：3-5 步即耗尽激活，输出截断
2. **同质化**：固定走边策略导致回复模式单一
3. **无模板感知**：输出纯实词拼接，缺少"的""对""有"等连接词

扩散引擎通过四层同步激活 + 侧抑制竞争，从根本上解决以上问题。

### 核心机制

#### 四层同步扩散

```
输入: "人 对 知识 有 渴望"
  ↓ 滑动窗口分词（trigram → bigram → unigram）
  ↓
词汇层: "人"→"的" "对" 等字面邻居
语义层: 9 子拓扑跨层联想，触达"学习""智慧"等
模板层: 匹配 "N 对 N 有 V" 模式
情绪层: valence × arousal 加权
  ↓ 四层同步约束
  ↓ 侧抑制（Lateral Inhibition）
  ↓ 竞争胜出
输出: "人对知识有渴望"
```

#### 滑动窗口分词

| 优先级 | 窗口 | 说明 |
|--------|------|------|
| 1 | trigram | 3 字连续匹配，最精确 |
| 2 | bigram | 2 字匹配，降级补充 |
| 3 | unigram | 单字匹配，兜底召回 |

#### 侧抑制

抑制共现频率过高的同质节点，保证输出多样性：
```c
// 若两个候选节点共现次数 > threshold，较低激活者被抑制
if (cooccurrence_count(a, b) > INHIBITION_THRESHOLD) {
    candidate[b].activation *= 0.3;  // 侧抑制衰减
}
```

#### 模板导向连接词

模板层概念中解析连接词模式（如 `"N的N是N"`），在输出实词间自动插入对应连接词：

| 模板模式 | 插入连接词 |
|----------|------------|
| `N的N` | 的 |
| `N对N有V` | 对、有 |
| `N是N` | 是 |

## 效果对比

| 指标 | 走边引擎 | 扩散引擎 |
|------|----------|----------|
| 输出长度 | 3-5 字 | 8-15 字 |
| 连接词 | 无 | 自动插入 |
| 回复多样性 | 低（同质化） | 高（侧抑制） |
| 语义相关性 | 中等 | 强（四层约束） |

## 设计决策

1. **为什么是扩散而非 Transformer？**  
   扩散过程模拟生物神经网络的激活传播，每一步都是可解释的（哪个节点被激活、为什么），而 Transformer 的 attention 权重难以追溯。

2. **四层约束会不会让回复更同质？**  
   会。因此侧抑制机制是关键——它强制输出多样性，避免所有路径都收敛到最高频连接。
