# 019 - v0.2.3 稳定性里程碑

## 详细改动

### 1. 堆损坏修复（Critical）

**问题**：`trace_wisdom_net_dynamic_add_node` 内部无去重检查，`handle_learn` 每次调用都往里塞节点。12 万次调用后堆碎片严重，最终 `malloc` 返回无效指针 → heap corruption。

**修复**：
- 在 `handle_learn` 层面恢复线性扫描去重，已存在的概念不再调用 `dynamic_add_node`
- 添加限流机制：每秒最多 50 次动态添加，burst=5

```c
// 限流逻辑
static time_t last_add_time = 0;
static int add_count = 0;
if (now - last_add_time > 1) { add_count = 0; last_add_time = now; }
if (add_count >= 50) return;  // 限流
add_count++;
```

### 2. 走边引擎 → 多层扩散引擎

**问题**：`dialog_process`（走边引擎）基于贪心走边生成回复，路径短、同质化严重。

**方案**：替换为 `diffusion_generate`（多层扩散引擎）：

| 属性 | 走边引擎 | 扩散引擎 |
|------|---------|---------|
| 策略 | 贪心选边 | 多层同步扩散 |
| 输出 | 单路径 | 多候选竞争 |
| 模板 | 无 | 连接词模式指导 |
| 情绪 | 未考虑 | valence×arousal 加权 |

**修改**：`src/prefrontal.c` 移除 `dialog_process` 调用，改为纯扩散生成。

### 3. 四层同步约束

扩散引擎在四个维度同时扩散，最终侧抑制选优：

- **词汇层**：直接字面匹配，快速召回候选
- **语义层**：9 子拓扑跨层联想，触达相关概念
- **模板层**：识别"N的N是N""N对N有V"等句式模式，指导连接词插入
- **情绪层**：valence × arousal 加权，影响候选优先级

滑动窗口分词：trigram → bigram → unigram 逐级降级匹配。

### 4. 模板导向输出

解析模板层概念中的连接词模式，在输出实词间插入对应连接词：

```
输入: "人 对 知识 有 渴望"
模板匹配: N 对 N 有 V → 插入"对""有"
输出: "人对知识有渴望"
```

### 5. 内存泄漏修复

`src/diffusion.c` 中模板解析使用 `strdup(conn)` 分配连接词字符串，但从未释放。

**修复**：改为栈池 `conn_pool[128]`，复用固定缓冲区，零分配零泄漏。

### 6. 概念哈希 O(1) 查找

`TraceWisdomNetwork` 新增 `concept_hash`（开放定址哈希表）和 `concept_hash_mask`：

| 指标 | 优化前 | 优化后 |
|------|--------|--------|
| 查找方式 | 线性扫描 O(n) | 哈希查找 O(1) |
| 万节点耗时 | ~200μs | ~2μs |
| 新增 API | — | `trace_wisdom_net_find_concept()` |

### 7. 扩散静态数组

`DiffusionCtx` 新增 4 个静态数组（`_vocab_scores` 等），避免每次扩散调用 `calloc/free`。

**效果**：消除扩散路径上的动态分配，减少 GC 压力和碎片。

### 8. 突触缩放（Synaptic Scaling）

每 600 tick 扫描全图所有边，按权重×置信度分层衰减：

```
权重 × 置信度 < 0.05  →  权重 × 0.9  （缓慢衰减）
权重 × 置信度 < 0.01  →  权重 × 0.5  （加速衰减）
权重 × 置信度 < 0.001 →  释放内存    （彻底清除）
```

**设计哲学**：AI 学到的东西不能直接砍掉，弱连接自然消退，强连接保留——不是删除，而是遗忘。

**实测效果**：连接数从 232 万降至 129 万（自动修剪 100 万+弱边），RSS 从持续增长变为锁定在 474MB。

### 9. 内感受自检模块（HealthMonitor）

新增模块，持续监测引擎"生理指标"，三级自动响应：

| 指标 | 🟡 YELLOW 预警 | 🔴 RED 紧急 |
|------|---------------|-------------|
| RSS 增速 | > 2MB/min | > 10MB/min |
| 连接膨胀 | 新增 > 50k/min | 新增 > 200k/min |
| 推理冻结 | 响应 > 2s 占比 > 30% | > 80% |

**响应策略**：
- 🟢 **GREEN**：正常运行，无干预
- 🟡 **YELLOW**：日志告警 + 自动提高学习门槛（限流）
- 🔴 **RED**：紧急状态存档 + 批量砍除弱边（权重×置信度 < 0.01 × 0.5 衰减）

**灵感**：AI 也应该有"不舒服的感觉"——不是被动崩溃，而是主动感知自身状态并自救。

### 10. 堆监控

`src/brainstem.c` 每 30 tick 输出：
- 节点数 / 连接数
- RSS / VSZ 内存占用
- 供观测和调试使用

### 11. 海马体对话记录

`hippocampus_log_dialog` 记录对话内容，巩固时自动建立 QA 连接，增强问答关联。

### 12. 感觉皮层优化

- `cycle_interval_ticks` 从 300 降至 50（6 倍频率提升）
- `curiosity_score_node` 降低门槛（连接 < 10 即有好奇心分数）
- 效果：更多概念被"注意到"，数据丰富度提升

### 13. DMN 扩散引导增强

随机游走后增加扩散引导，让默认模式网络产出更具方向性的"念头"。

## 设计决策记录

1. **"约束越多回复越同质"** → 不再加规则约束，改为提升数据丰富度（感觉皮层、海马体、DMN）
2. **"AI 学到的东西不能直接砍掉"** → 突触缩放改为衰减而非删除，保留生物合理性
3. **"AI 也应该有不舒服的感觉"** → 内感受自检模块的设计灵感，引擎能感知自身状态并自救
