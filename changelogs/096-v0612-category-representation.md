## 一、这一版是什么

三件事叠在一天里，彼此有依赖顺序：

1. **词表从「垃圾堆」重建**（重训管线）——原来 57% 的节点是垃圾，词层长不出来。

## 三、词类分类的表示层（本条是重点）

### 3.1 病根

`emergent_pos_classify_soft()` 用 `cosine(features, anchor->centroid, 512 维)` 做分类，
而 features 在重训时是 `rand()*0.1-0.05`（`tools/qa_retrain.c:83`）—— **随机噪声**，
余弦在噪声上没有语义，分类结果等于随机。

本该是正确表示的 `dist_sig[26]`（左右邻 POS 分布）实测**全空**：
`[0..21]` 全 0，只有位置先验 `[22][23]` 有点值，`dist_sig_count` 仅 **0–18 次**
（而语料有 1.09 亿次观测）。原因：重训工具不调 `emergent_pos_update_dist_sig`。

### 3.2 做法：一阶分布指纹 `src/word_embed.c`

照 Schütze (1993/1995) 的分布聚类简化版：

- 特征维 = 频次 **top-300 单字**（Zipf：这批几乎全是功能字）
- 向量 = 左邻计数[300] + 右邻计数[300] → **PPMI** → L2 归一化
- 数据源 = `charpairs.bin`（字符级**有序**共现）
- 落盘 `data/word_embed.bin`：7,061 词 × 600 维，17 MB；缺失时懒构建 1.6 秒

**为什么不用拓扑边**：实测词节点的边是「同句共现的兄弟」
（电脑↔屏幕↔坏了，权重 0.6–0.8），**不含方向**；charpairs 是有序字对才分得出左右邻。

接入点：`emergent_pos_tag_soft()` 在「种子精确匹配」之后、「512 维特征软匹配」之前，
用**类种子原型（均值）**比余弦，取前 3 名软输出。指纹不可用（多字词 / 表外字 /
非零维 < 3）⇒ 原样落回旧路径，行为不变。开关 `PIVOTMIND_POS_EMBED=0`。

### 3.3 指标

**表示质量**（类内 / 跨类平均余弦比，`tools/wemb_probe.c`）：

| 加权方式 | 类内 | 跨类 | 比值 |
|---|---|---|---|
| **PPMI（采用）** | 0.083 | 0.025 | **3.28x** |
| sqrt(TF)×IDF（试过，已退） | 0.449 | 0.342 | 1.31x |

单点：`很~太 0.468`（同副词）· `很~山 0.166` · `吃~的 0.089` · `人~山 0.003`

**分类准确率**（25 个**非种子词**；种子会被第一层 `strcmp` 直接命中，测不出指纹层）：
**20/25 = 80%**，25 个全部给出类别，无「未分类」。

- 对：走拿写唱→动词 · 更太也又→副词 · 树河车鱼门→名词 · 过呢→助词
- 错：睡→名词 · 还→连词 · 甜→数词 · 苦→叹词 · 冷→介词（这几个中文本就兼类）

80% 与 Haghighi & Klein (2006)「每类仅 3 个种子词达 80%」对得上 ⇒ 种子表规模够。

### 3.4 已知限制

1. **类内向量趋同**：名词类内余弦 ≈0.995，`%.2f` 显示成 1.00。成因是特征词几乎全是
   功能字 ⇒ 同一语法类方向必然趋同。对「判词类」无害，但**置信度没有区分度，不能当概率用**。
2. **多字词无指纹**：charpairs 是字符级，29,480 个双字词仍走回退路径。
3. **线上尚未被调用**：对话全被 QA 记忆截走（见第六节 CX-32），`tag_soft` 只在学新词时触发。

## 四、词概率体系（`src/word_prob.c`）

`charpairs.bin` 从「只认中文单字」扩成**中英双轨 token 对**（键 8 → 32 字节）。
`word_prob` 从计数**现算** P(w) / 左熵 / 右熵 / PMI（派生量不落盘）。

| 接入点 | 作用 |
|---|---|
| `diffusion.c` 候选打分 | 乘 `wp_gain(词)`：概率高↑、min(左右熵) 高↑、低概率低熵↓；**单字豁免恒 1.0** |
| `gateway_learn.c:296` | 每喂一次料 `cp_observe_tokens` 累加 ⇒ **概率随学习演化** |
| `/debug` | 露 `wp_tokens / wp_pairs / wp_total` |

实测：问题 7,595 次 min熵 4.52 增益 1.075 ↑ · 学习 6,090 次 6.29 → 1.067 ↑ ·
天气 691 次 5.30 → 0.988 → · 编译 58 次 3.49 → 0.873 ↓

🔴 **中文多字词必须由字对合成**（首版漏了 ⇒「天气/学习」概率恒 0、增益恒 1，等于没接）。
🔴 **空白是软分隔**（英文靠它成词；当断链会让英文计数恒 0）。
🔴 「3 字节 ≠ 汉字」：全角标点也是 3 字节，必须校验 U+4E00..U+9FFF。

## 五、两个指标陷阱（都吃了亏，记下来）

### 5.1 三个上限叠起来，把词表砍掉 44%，且不报错

| 上限 | 实际数据 | 后果 |
|---|---|---|
| `cp_observe_tokens` 把全角标点当汉字 token | —— | 造出「者：」这种词，污染 PMI/熵 |
| `word_prob` 索引上限 `WP_PAIR_MAX=600k` | 836k 对 | 熵/PMI 只看到 2/3 数据 |
| 词晋升缓冲 400k + `PIVOTMIND_EMERGE_MAX=20k` | —— | 哈希槽序遍历≈随机抽 43%，再加帽 |

修后 2 万 → **3.55 万**。独立探针 `tools/pair_gate_probe.py` 全量重算理论值 31,167（差 5%）。

⇒ 规矩：**跑完必须用独立探针按同一判据全量重算一遍，别信工具自己的统计**；
「长度/数量上限」先问清**单位**与**实际规模**。

### 5.2 类内绝对值涨了，区分度却崩了

见 3.3 表格：TF-IDF 让类内从 0.083 涨到 0.449（看着大幅改善），
但跨类从 0.025 涨到 0.342，比值 3.28x → 1.31x。**指标要看比值，不看绝对值。**

### CX-33 的机制细节

不放回候选池（会让「的/了/在」劫持话题，v0.6 用 `degree_penalty` + `relevance` 专门修过），
改在已排序实词之间插关节，两级判据：

- 词级桥：`A --w1--> fw --w2--> B`（fw 为虚词）
- 字级桥：A 的**末字** `--c1-->` fw `--c2-->` B 的**首字**（charpairs 字符共现，两侧各 ≥3 次）

🔴 **词级桥实测 0 命中** —— 词节点的边是「同句共现的兄弟」不是语法后继。必须靠字级桥。

实测：`电脑屏幕坏了 → 随便**是**电脑**的**脑屏**的**屏幕` ·
`人工智能是什么 → 什么**是**学习` · `今天天气不错 → 我们不**去**爬**的**爬山`
